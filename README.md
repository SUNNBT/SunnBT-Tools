# SunnBT Tools

一个 **Minecraft 1.8.9 Forge 客户端模组**：进服自动 `/register` + `/login`，离线账号改名并一键重连。所有功能都能在游戏自带的 **Mods → SunnBT Tools → Config** 界面里改，改完立即生效并写入 `config/sunnbtmods.cfg`。

A client-side Forge mod for Minecraft 1.8.9: automatic register/login on server join, plus offline account renaming. Everything is configurable from the built-in Forge config screen.

---

## 功能

### 1. 自动登录

- 进入服务器后，在**设定的时间窗**（默认 40 秒）内监听聊天栏。
- 命中**注册提示**（`/register`、`/reg`、`请注册`、`请先注册`、`please register` 等）→ 发送 `/register <密码> <密码>`。
- 命中**登录提示**（`/login`、`/l`、`请登录`、`请先登录`、`please login` 等）→ 发送 `/login <密码>`。
- 默认**发过 `/register` 就不再发 `/login`**（开关 `sendLoginAfterRegister`，默认 `false`）。
- 聊天里出现「注册成功 / 登录成功 / successfully logged in」等成功提示时，立刻停止检测。
- 自己指令的回显里含密码，会被自动忽略，不会自己触发自己。
- 时间窗内 `/login` 最多发送 3 次（`maxLoginAttempts`，可改）。
- 服务器提示「already registered / 已被注册」时，直接转去发送 `/login`。

### 2. 离线账号改名

- **Offline Accounts 按钮**：多人游戏服务器列表左上角，用来管理离线账号名单。
  - 名单保存在 `config/autorename-accounts.txt`，一行一个名字。
  - 支持添加、删除、随机生成名字。
- **Rename & Rejoin 按钮**：断线界面出现，点一下就把客户端身份换成选中的离线账号并**自动重连**（默认延迟 15 tick ≈ 0.75 秒）。
- 离线 UUID 用 `UUID.nameUUIDFromBytes("OfflinePlayer:" + 名字)`，和原版离线模式一致，服务端不会认成新玩家。
- 名字允许 `a-z A-Z 0-9 _`，长度 3–16（可改）；随机名 = 配置里的前缀 + `_` + 5 位随机字符。

### 3. 配置界面

- 入口：主菜单 → **Mods** → 选中 **SunnBT Tools** → **Config**（Forge 原生配置界面，不是自绘的假菜单）。
- 17 个可编辑项，分 `autologin` / `autorename` 两类，全部真实生效。
- 点 Done 会写回 `config/sunnbtmods.cfg`；下次启动自动读取。
- 逐项说明见 [`docs/CONFIG.md`](docs/CONFIG.md)。

## 安装

1. 装好 **Forge 1.8.9**（推荐 `1.8.9-11.15.1.2318-1.8.9` 或更高）。
2. 把 `SunnBT-1.8.9-1.3.0.jar` 放进 `.minecraft/mods/`。
3. 启动游戏 → 主菜单进 Mods 列表确认能看到 **SunnBT Tools**。
4. 首次启动会生成 `config/sunnbtmods.cfg`，改密码就在那里或 Config 界面里改。

> 纯客户端模组，服务端不用装。

## 默认指令

| 场景 | 发送内容 |
| --- | --- |
| 检测到注册提示 | `/register sunnbt111 sunnbt111` |
| 检测到登录提示 | `/login sunnbt111` |

密码统一存在配置项 `password`（默认 `sunnbt111`），指令模板里的 `%password%` 会被替换成它。想改成别的指令模板，直接在配置里改 `registerCommand` / `loginCommand`。

## 从源码编译

需要 **JDK 8**（不要用 17/21，ForgeGradle 2.1 跑不了）。

```bash
git clone https://github.com/SUNNBT/SunnBT-Tools.git
cd SunnBT-Tools

# Linux / macOS
JAVA_HOME=/path/to/jdk8 ./gradlew build

# Windows (CMD)
set JAVA_HOME=C:\path\to\jdk8
gradlew.bat build
```

产物在 `build/libs/SunnBT-1.8.9-1.3.0.jar`。

首次编译会联网下载 ForgeGradle、Minecraft 1.8.9 与映射表，请保持网络通畅。

### 常见编译问题

| 现象 | 原因与处理 |
| --- | --- |
| `only supports Forge 1.8 before 11.14.3.1503` | 插件必须写 `apply plugin: 'net.minecraftforge.gradle.forge'`，写成 `forge` 会走错分支 |
| 映射相关报错 / 找不到 `snapshot_20141001` | 必须显式写 `mappings = "stable_22"`，默认映射只对 1.8 有效 |
| `Could not determine java version from '17.x'` | 本机 Gradle 用了高版本 JDK。加 `-Dorg.gradle.java.home=<你的JDK8路径>` 覆盖，或直接设 `JAVA_HOME` |
| 中文注释乱码 | `compileJava { options.encoding = 'UTF-8' }` 已在 `build.gradle` 里设好 |

## 已知限制

- 只针对 **1.8.9**，其他版本需要改映射与 ForgeGradle 版本。
- 需要在服务器允许 `/register`、`/login`；登录插件指令不同的话请改指令模板。
- 离线改名只在**离线模式 / 接受离线身份**的服务器上有效，正版验证服务器会拒绝。
- 密码以明文存在 `config/sunnbtmods.cfg`，介意的话自己控制文件权限。
- 已做过编译与静态验证（reobf 映射、配置界面注册链路、保存链路），GUI 交互与进服行为请在实际客户端里确认。
